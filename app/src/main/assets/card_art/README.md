# Card artwork drop-in folder

Add verified, original full card-face images here. The app loads them automatically using the card name slug (lowercase letters, digits, underscores), for example:

- `hexguard.webp`
- `cursed_thrall.png`
- `paradoxical_neophyte_s_shade.jpg`
- `shinka_decurion.webp`

Supported extensions: `.webp`, `.png`, `.jpg`, `.jpeg`. Bundled files take priority over online art. Avoid recreations or images of the same Destiny enemy that are **not** actual Shadowshaper card faces. Missing artwork remains clearly labeled in the viewer.
